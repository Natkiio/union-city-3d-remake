# Status

One file per workstream: `status/<name>.md`, at most 15 lines, rewritten (not appended) at each milestone.

```
# <name>  —  <Doing | Blocked | Done>
Branch: feat/<name>
Done: ...
Doing: ...
Blocked: ...
Next: ...
Tests: tests/test_<name>.gd  <n pass / n fail>
```

`status/BOARD.md` is the one-screen overview, kept by the lead.
